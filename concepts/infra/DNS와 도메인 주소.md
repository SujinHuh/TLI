# DNS와 도메인 주소

## 한 줄 정의
DNS는 사람이 읽기 쉬운 도메인 이름을 컴퓨터가 접속할 서버나 로드밸런서의 주소 정보로 찾아주는 시스템이다.

## 핵심 내용
사용자는 서버의 IP 주소를 직접 외우는 대신 `example.com` 같은 도메인 이름을 사용한다.

DNS는 도메인 이름에 연결된 주소 정보를 찾아 클라이언트가 접속할 위치를 알려준다.

```text
사용자
  -> example.com 접속
  -> DNS에 주소 조회
  -> 서버 또는 로드밸런서 주소 확인
  -> 해당 주소로 요청 전송
```

DNS가 웹 요청 자체를 처리하는 것은 아니다.

DNS는 먼저 접속할 주소를 알려주고, 실제 HTTP 요청은 그다음에 서버나 로드밸런서로 전달된다.

## 예시
사용자가 `shop.example.com`에 접속한다고 가정한다.

```text
shop.example.com
  -> DNS 조회
  -> Load Balancer 주소 확인
  -> Load Balancer
  -> Application Server
```

## 주의할 점
- DNS는 도메인 이름에 연결된 주소 정보를 찾아주는 시스템이다.
- DNS가 애플리케이션의 실제 요청을 직접 처리하는 것은 아니다.
- DNS 조회 결과는 일정 시간 캐시될 수 있어 주소를 변경해도 바로 반영되지 않을 수 있다.
- DNS와 로드밸런서는 다르다. DNS는 접속할 주소를 안내하고, 로드밸런서는 도착한 요청을 서버에 분배한다.
