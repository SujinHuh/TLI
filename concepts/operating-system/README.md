# 운영체제 공룡책

## 책
- 『Operating System Concepts』
- 국내에서는 표지의 공룡 그림 때문에 흔히 "공룡책"이라고 부른다.

## 목차
- 읽은 장부터 장별 정리 문서를 추가한다.

## 정리 기준
- 책을 읽으며 이해한 핵심 내용을 장별로 정리한다.
- Daily에는 그날의 학습 흐름을 남기고, 이 디렉터리에는 다시 보기 좋은 장별 개념 정리를 남긴다.
- 프로세스, 스레드, CPU 스케줄링, 동기화, 데드락, 메모리, 가상 메모리, 파일 시스템처럼 면접과 실무에서 다시 볼 가능성이 큰 주제는 별도 개념 문서로도 분리할 수 있다.
