# 학습 기록 작성 흐름

이 문서는 Codex와 함께 TLI 학습 기록을 작성하고 GitHub에 올릴 때 따르는 작업 흐름을 정의한다.

## 기본 원칙

- 학습 기록 파일은 Markdown 형식으로 작성한다.
- Codex가 먼저 학습 기록 초안을 작성한다.
- 사용자가 승인하기 전에는 파일 생성, commit, push를 하지 않는다.
- 기록 포맷은 `목표 / 완료 / 공부 시간 / 회고` 순서를 따른다.

## 작성 흐름

1. 사용자가 "git에 올려줘"라고 요청한다.
2. Codex가 오늘 학습 내용을 정해진 포맷에 맞춰 먼저 초안으로 정리한다.
3. 사용자가 초안을 확인하고 승인한다.
4. 승인 후 Codex가 `.md` 파일을 생성한다.
5. 파일명은 `YYYY-MM-DD(요일) 소제목.md` 형식으로 작성한다.
6. 생성한 파일을 commit/push 한다.

## 공부 시간 기록 기준

- 공부 시간은 기본적으로 Codex와 해당 학습 주제 대화를 시작한 시각부터 기록 요청 시점까지로 계산한다.
- 시간이 불명확한 경우 사용자가 말한 시간을 우선한다.
- 사용자가 별도로 공부 시간을 알려주면 해당 시간을 그대로 기록한다.

## 주의사항

- 사용자가 승인하기 전에는 절대 commit/push 하지 않는다.
- 초안은 사용자가 수정할 수 있으므로, 승인 전까지는 최종 기록으로 간주하지 않는다.
- 하루에 여러 주제를 공부했더라도 하나의 날짜 파일 안에 자연스럽게 묶어 기록한다.
