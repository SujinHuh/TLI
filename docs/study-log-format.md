# 학습 기록 포맷

이 문서는 TLI 저장소에 날짜별 학습 기록을 작성할 때 사용하는 Markdown 포맷을 정의한다.

## 저장 위치

날짜별 학습 기록은 아래 위치에 저장한다.

```text
daily/YYYY/YYYY-MM-DD(요일) 소제목.md
```

예시:

```text
daily/2026/2026-04-01(수) 요청 흐름 딥다이브 다시 보기.md
```

개념별 정리 문서는 아래 위치에 저장한다.

```text
concepts/주제/개념명.md
```

예시:

```text
concepts/spring/dependency-injection.md
concepts/database/connection-pool.md
concepts/infra/api-gateway.md
```

## 파일명 규칙

파일명은 아래 형식을 따른다.

```text
YYYY-MM-DD(요일) 소제목.md
```

예시:

```text
2026-04-01(수) 요청 흐름 딥다이브 다시 보기.md
```

## 본문 포맷

학습 기록 본문은 아래 항목 순서로 작성한다.

```md
# 📅 YYYY-MM-DD(요일) 제목

## 🎯 목표
없음

## ✅ 완료
- 완료한 학습 내용 1
- 완료한 학습 내용 2

## ⏱️ 공부 시간
HH:mm ~ HH:mm (총 N시간 N분)

## ✍️ 회고
사용자가 직접 작성한다.

## 🔗 관련 Concepts
- `concepts/주제/개념명.md`
```

## 작성 예시

```md
# 📅 2026-04-01(수) 요청 흐름 딥다이브 다시 보기

## 🎯 목표
없음

## ✅ 완료
- API Gateway 중심으로 요청 진입/라우팅/횡단 관심사 관점 다시 정리
- DynamoDB -> Streams -> Kafka로 이어지는 상태 변경 이벤트화/전파 흐름 복습

## ⏱️ 공부 시간
20:30 ~ 23:00 (총 2시간 30분)

## ✍️ 회고
날씨가 쌀쌀하면서도 따뜻해서 감기/몸살 걸리기 딱 좋은 느낌이다.
시차 출근제로 오늘도 08:00 출근은 성공했고, 중간중간 영상/개념 보면서 "왜 이런 기술이 나왔고 왜 쓰는지" 꼬리 질문을 계속 해봤다.
이게 제대로 딥다이브가 맞는지는 아직 모르겠지만, 그래도 조금씩 흥미를 찾는 것 같다.

## 🔗 관련 Concepts
- `concepts/infra/api-gateway.md`
```

## Concepts 포맷

개념 정리 문서는 아래 항목을 기준으로 작성한다.

```md
# 개념명

## 한 줄 정의
개념을 한 문장으로 정리한다.

## 핵심 내용
- 핵심 내용 1
- 핵심 내용 2

## 예시
간단한 예시나 흐름을 정리한다.

## 주의할 점
- 헷갈리기 쉬운 점
- 실무에서 조심할 점

## 관련 Daily
- `daily/YYYY/YYYY-MM-DD(요일) 소제목.md`
```
