## 🎯 목표

- Redis가 캐시처럼 쓰인다는 말의 의미 정리하기
- 처리율 제한에서 Redis가 왜 필요한지 감 잡기

## ✅ 완료
- Cache는 특정 기술명이 아니라 자주 쓰는 데이터를 가까운 곳에 잠깐 저장해 빠르게 꺼내 쓰는 역할이라는 점 정리
- Redis는 메모리 기반 key-value 저장소이며 캐시, 세션, 처리율 제한 카운터 등으로 사용할 수 있다는 점 정리
- Kafka는 캐시가 아니라 이벤트와 메시지를 쌓아두고 서비스 간 비동기 처리를 돕는 플랫폼이라는 점 정리
- Redis는 보통 API Server와 DB 사이에서 빠른 조회나 공유 상태 저장에 쓰이고, Kafka는 서비스와 서비스 사이에서 이벤트 전달에 쓰인다는 차이 확인
