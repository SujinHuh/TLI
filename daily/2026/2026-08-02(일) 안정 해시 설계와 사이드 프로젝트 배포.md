- 수평적 규모 확장성과 수직적 규모 확장의 차이 복습
- 안정 해시는 수평 확장 자체가 아니라, 수평 확장된 서버들 사이에 데이터를 안정적으로 분배하기 위한 기법이라는 점 정리
- 안정 해시에서 서버 식별자와 데이터 key를 모두 해시 링 위에 배치한다는 흐름 이해
- 해시 서버는 별도의 서버 종류라기보다 서버를 해시해서 링 위에 배치한 서버 노드라는 점 확인
- 해시 키는 데이터를 어느 서버에 보낼지 정하기 위해 해시하는 데이터 식별자라는 점 정리
- 기본 구현법에서 서버 키를 균등 분포 해시 함수로 해시 링에 배치하고, 키 위치에서 시계 방향으로 탐색해 처음 만나는 서버에 저장하는 흐름까지 읽음
- 기본 구현법에 두 가지 문제점이 있다는 지점까지 읽었고, 내일은 그 문제점부터 이어 읽기로 함
