# 📅 2026-07-21(화) 처리율 제한 위치와 계층별 역할 복습

## 🎯 목표
- 가상면접 4장 처리율 제한 장치 개념 이어서 공부하기
- 처리율 제한을 둘 수 있는 위치를 인프라 앞단 계층과 애플리케이션에 가까운 계층으로 나누어 설명하기

## ✅ 완료
- 처리율 제한이 단순히 연속 API 호출을 막는 장치가 아니라, 목적에 따라 보안/방어 목적과 서비스 정책 목적으로 나뉜다는 점 정리
- DDoS, 봇, 비정상 대량 요청 차단은 CDN, WAF, Reverse Proxy 같은 인프라 앞단 계층에서 처리하는 것이 적합하다는 점 복습
- 사용자별, API별, 요금제별 사용량 제한은 인증 정보와 사용자 정보를 알 수 있는 API Gateway나 Application Middleware에서 처리하는 것이 적합하다는 점 정리
- CDN, WAF, Load Balancer, Reverse Proxy, API Gateway, Application Middleware의 역할을 요청 흐름 순서로 다시 확인
- API Gateway와 Application Middleware의 차이를 개발자 관점으로 정리
  - API Gateway: 여러 서비스 앞의 공통 관문
  - Application Middleware: 특정 애플리케이션 내부의 Controller 이전 처리 흐름
- Spring 기준 Application Middleware가 Filter, Interceptor, AOP, Spring Cloud Gateway Filter 같은 계층과 연결된다는 점 확인
