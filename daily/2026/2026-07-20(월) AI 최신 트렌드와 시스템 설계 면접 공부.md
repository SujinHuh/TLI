# 📅 2026-07-20(월) AI 최신 트렌드와 시스템 설계 면접 공부

## 🎯 목표
- 가상면접 공부 이어가기
- 내 프로젝트 만들기
- AI 최신 트렌드를 따라가기 위한 개인용 AI 아티클 구조 고민하기

## ✅ 완료
- 처리율 제한 장치의 위치를 인프라 앞단 계층과 애플리케이션에 가까운 계층으로 나누어 이해
  - CDN, WAF, Load Balancer, Reverse Proxy
  - API Gateway, Application Middleware
- DDoS 방어 목적의 제한과 사용자별, API별, 요금제별 비즈니스 정책 목적의 제한이 다르다는 점 정리
- Reverse Proxy가 Spring 자체를 의미하는 것이 아니라, 보통 Spring 애플리케이션 앞단에서 요청을 받아 내부 서버로 전달하는 프록시 계층이라는 점 확인
- API Gateway와 Application Middleware의 차이를 다시 정리
- AI 최신 트렌드를 따라가기 위한 개인용 AI 아티클/문서화 구조를 고민
- 출근길에 LLM 노트북을 활용해 듣는 방식으로 AI 최신 이슈를 따라가는 흐름 구상
- 하네스 프로그램, 루프 엔진 같은 키워드도 계속 공부할 필요가 있다고 느낌
- DNS, 미들웨어 관련 개념을 면접 관점에서 다시 확인
- 운영체제의 PCB, 제어 블록 관련 키워드를 다시 복습

## ⏱️ 공부 시간
19:30 ~ 22:47 (총 3시간 17분)

## ✍️ 회고
AI가 하루에도 몇 번씩 업데이트가 되고, 그 사용하는 최근 이슈들도 빠르게 따라가지 못하면 안 될 것 같았다.
그래서 개인적으로 AI 아티클 같은 거를 만들려고 한다.
우선은 나만 보고, 출근할 때 LLM 노트북을 사용해서 듣는 걸로 활용해서 AI 최신 트렌드를 따라가려고 한다.
하네스 프로그램, 루프 엔진 이런 키워드 같은 것도 필요할 것 같아서 지금 이런 거 공부 중이다.

그래서 이거를 아키텍처를 만들고, 문서화를 지금 시키는 중이다.
그러면서 DNS 관련한 부분, 미들웨어 관련한 부분을 가상면접 공부로 같이 보고 있다.
알고 있는 단어들이었는데, 이거를 하나하나씩 다시 들어가 보니까 다시 새롭게 아는 점이 있었다.

운영체제 관련한 것도 BCD? PCB라는 것도 학부 때 공부했었던 내용인데, 다시 한 번 보고 공부하니까 이것도 새롭게 다시 알게 되는 점이었다.
제어 블록 관련한 것도 다시 한 번 키워드를 공부하게 되었다.

참고로! 자기 전에 웬만하면 핸드폰 쇼츠를 보지 않고, 내가 읽고 싶은 책을 한 40분 정도 읽으니까 약간 도파민에 절여져 있던 내가 깨끗해지는 느낌이랄까?
요즘에 이런 루틴을 쭉 유지하려고 한다.
