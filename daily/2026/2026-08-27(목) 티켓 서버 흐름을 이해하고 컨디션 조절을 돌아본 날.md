# 📅 2026-08-27(목) 티켓 서버 흐름을 이해하고 컨디션 조절을 돌아본 날

## 🎯 목표
- 가상면접 7장 ‘분산 시스템을 위한 유일 ID 생성기’ 이어서 학습
- Ticket Server의 동작 방식과 라운드로빈의 차이 이해

## ✅ 완료
- Ticket Server가 여러 웹 서버에 중복되지 않는 데이터 ID를 중앙에서 발급하는 구조임을 이해
- 로드밸런서가 라운드로빈 방식으로 웹 서버 한 대를 선택하고, 선택된 웹 서버가 내부 처리 과정에서 Ticket Server에 ID를 요청하는 전체 흐름 확인
- Ticket Server가 웹 서버의 ID가 아니라 새로 저장할 회원·사진·주문 등의 데이터 ID를 발급한다는 점 확인
- Flickr가 사람이 아니라 사진 공유 서비스이며, Flickr 개발팀이 분산 데이터베이스 전체에서 중복되지 않는 기본키를 만들기 위해 Ticket Server를 사용했다는 점 확인
- Ticket Server의 단순한 구조, 숫자형 ID, 발급 순서에 따른 증가와 ID 중복 방지 장점 확인
- Ticket Server의 병목, 단일 장애점과 단순 다중화 시 ID 충돌 가능성 확인
- 라운드로빈과 Ticket Server는 한 시스템에서 함께 사용할 수 있지만 서로 반드시 함께 사용해야 하는 기술은 아니라는 점 확인

## ⏱️ 공부 시간
약 1시간 조금 넘게 (사용자 추정, 시작·종료 시각 기록 없음)
