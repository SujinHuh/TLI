## 확인한 회사 정보

텔코웨어는 통신망의 핵심인 Core Network 솔루션 개발을 주력으로 하는 회사다. 공식 홈페이지의 회사 개요에서는 Core Network 솔루션을 중심으로 보안 IoT, Cloud, 빅데이터, AI 융합으로 사업 영역을 확대한다고 설명한다.

공식 채용 직무 소개 기준 개발 직무는 Core Network 솔루션, IP Multimedia Subsystem, 미디어 서버, 보안 IoT 솔루션, AI 융합 솔루션 개발 업무를 수행한다. 운영체제, 프로그래밍 언어, 네트워크, 알고리즘, 데이터베이스 지식을 바탕으로 프로그램을 설계, 개발, 분석한다고 되어 있다.

Web Application 개발 직무에는 아래 키워드가 직접 등장한다.

- Web Application back-end 개발
- ICT Solution Server 개발 및 프로젝트 리딩
- Java 언어 중급 이상
- Spring Framework 또는 Spring Boot 기반 Web Application 개발
- RDB, MariaDB, PostgreSQL 사용 및 DBMS 설계 경험 우대
- Gradle 및 Tomcat 기반 빌드/배포 전략 경험 우대
- MSA, RESTful 등 디자인 아키텍처 경험 우대

## 필기시험 대비 방향

4~5년차 Java 백엔드 포지션이지만, 일반 웹 서비스 회사와 다르게 통신 Core Network 솔루션 회사라는 점을 반영해야 한다.

우선순위는 아래처럼 잡는다.

1. Java 기본기와 동시성
2. Spring Boot, REST API, 트랜잭션
3. RDB, SQL, 인덱스, 트랜잭션 격리 수준
4. Linux, 네트워크, TCP/IP
5. 알고리즘과 자료구조
6. 서버 장애 분석, 로그, 배포
7. MSA, Tomcat, Gradle
8. 통신 도메인 기초: IMS, 5G Core, VNF/CNF, 고가용성
